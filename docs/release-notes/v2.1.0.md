## 更新内容

- 安装界面升级：更清晰的中文字体、统一的 BoltSnip 品牌欢迎页和完成页，并跟随 Windows 深浅色设置。
- 语言选择采用圆角下拉控件、更宽松的行距、柔和选中态和勾选标记，支持中英文和键盘选择。
- 同步 main 上的即时回放自动开启设置，保留授权管理入口以及现有录音和回放设置。

## 下载与安装

下载 `BoltSnip-Setup-2.1.0-win-x64.exe`。安装包内包含 FFmpeg，无需另行下载。

支持 Windows 10/11 x64 和 .NET Framework 4.8；即时回放需要支持 NVENC 的 NVIDIA 显卡。升级前请保存需要保留的回放，并退出旧版程序。现有设置与授权凭据保留。

完整性校验文件：`SHA256SUMS.txt`。
