# Changelog

This file tracks public BoltSnip release notes. Internal implementation details and source changes are intentionally omitted.

## v1.0.0 — 2026-09-25

First stable Windows release of BoltSnip.

- Window capture and precise free-region capture
- Global hotkey, magnifier, alignment guides, clipboard copy and quick save
- Online activation code and offline license-file support
- Authorization management from the system tray
- Running version shown in tray menu and tooltip
- Per-user installer for Windows 10/11 x64
- Requires .NET Framework 4.8
